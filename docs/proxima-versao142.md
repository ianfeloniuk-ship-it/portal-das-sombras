# Próxima versão — v142

Camadas visuais das habilidades passam a variar por família de classe e função: materiais elementais texturizados, formas próprias para disparos, áreas, golpes e proteções, com animação leve. As 21 classes usam as famílias de materiais já definidas. Mantidos dano, custo, alcance, colisão, recarga, direção de mira e duração das habilidades.
