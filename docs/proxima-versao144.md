# Próxima versão — v144

Ajustei o caminho de lançamento para que as silhuetas visuais das 21 classes apareçam também nas habilidades atuais, incluindo as habilidades especiais. Ao acertar a sequência de três habilidades diferentes em até 6,5 segundos, um selo de Ressonância Tripla conecta as três famílias visuais.

A sequência é apenas visual: não concede dano, mana ou recarga extra. O combate, os alvos e os tempos seguem iguais.
