# Ecos da Fenda / Portal das Sombras — passagem de contexto (v183 → v251, 05/10/2026)

Para qualquer IA continuar de onde paramos. O histórico completo, versão a versão, está em `CONTEXTO.md` na raiz do repositório (`ianfeloniuk-ship-it/portal-das-sombras`, branch `main`). Jogo: https://ianfeloniuk-ship-it.github.io/portal-das-sombras/

## Como trabalhar no repositório
- `game.html` é a fonte única. `index.html` é gerado por `python3 tools/build.py`; nunca editar à mão.
- Alguns `tools/*.js` são sincronizados para dentro do `game.html` pelo build (ex.: `environment128.js`, `crystals125.js`, `kit111-runtime.js`, `habitat-render124.js`): editar no `tools/`.
- Carregados à parte com `?v=` (subir o número ao mudar): `tools/warrior-player127.js`, `tools/rift131.js`, `tools/terrain245.js`.
- Lançamento: subir `pds-vN` no `sw.js` → build duas vezes e comparar → linha no `CONTEXTO.md` → commit → push na branch de trabalho e em `main`.
- Blender 4.2 (bpy) foi usado para rig e animações: `tools/blender242/`, `tools/blender246/rig_arquiteto.py`.
